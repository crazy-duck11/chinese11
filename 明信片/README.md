# 衣见中华 · 民族邮局 UI 原型

## 使用
解压后直接打开 `index.html` 即可预览，无需安装依赖或联网。

## 已实现
- 淡色中国风首页和邮局主题
- 选择明信片、输入 200 字以内寄语
- 寄出后等待约 5 秒
- 从 3 款预设回信中随机抽取一封
- 点击信箱重新查看回信
- 明信片册：全部、我寄出的、收到的
- 手机与桌面响应式布局

## 注意
这是可交互前端原型，页面数据刷新后会重置。视觉物件使用 CSS 插画占位，后续可以替换成单独透明 PNG/SVG。`assets/visual-reference-board.png`（若存在）为设计参考合集图，不是拆分后的透明素材。
